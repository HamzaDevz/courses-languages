# Enregistrements audio

Le site prononce déjà les mots avec la voix du système (synthèse vocale du
navigateur), donc ce dossier est **optionnel**.

Pour de vraies voix humaines : déposer les fichiers ici, un dossier par langue
(`pt/`, `ar/`), nommés d'après le mot (`bom-dia.mp3`), puis ajouter
`audio: bom-dia.mp3` à l'entrée du YAML.
